{% comment %} Site dialog: replaces window.confirm / alert / prompt with a styled, animated modal that matches the customer side. Self-contained (markup + CSS + JS) with its own .ara-dlg-* namespace and no Tailwind dependency, so the standalone templates that don't extend base.html can include it with one line. API (all return a Promise): arabelaConfirm({title, message, confirmText, cancelText, danger}) -> bool arabelaAlert({title, message, confirmText}) -> true arabelaPrompt({title, message, placeholder, confirmText}) -> string|null NOTE: must be {% comment %}, not {# #} -- Django's hash comment is single-line only, so a multi-line one renders as visible text on every page including it. {% endcomment %}
