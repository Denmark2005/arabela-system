{% comment %} "Upload your receipt" window for the booking pages (My Reservations and a booking's own page): the customer types the GCash reference number and the amount from their receipt and chooses the screenshot, all in one place, because the server compares what was typed with the picture (gowns/typed_payment.py). Self-contained (markup + CSS + JS, own .ara-pd-* names, no Tailwind), like partials/dialog.html, so pages that do not extend base.html can include it with one line. Needs static/js/proof-details.js and static/js/picked-file.js on the page. API: arabelaAskProofDetails({ due, values: {reference, amount, file}, errors: {reference, amount, file} }) -> Promise of { reference, amount, file } when the customer presses Upload with everything filled in, or null when they cancel. `values` re-fills the boxes (and keeps the chosen picture) after the server asked them to look again; `errors` shows a sentence under a box. NOTE: must be {% comment %}, not {# #} -- Django's hash comment is single-line only. {% endcomment %}
