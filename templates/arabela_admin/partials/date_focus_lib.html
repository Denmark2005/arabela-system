{% comment %} The small helper behind the "On this date" bar (partials/date_focus.html): one exact date, and what it means (pick-up, return or event). Included ONCE per admin page from partials/notifications.html, as a plain inline script so it exists before any page script asks for it. Every page that filters by date marks its rows with three attributes, each holding the dates (YYYY-MM-DD, space separated) of that row's gowns: data-d-pickup="2026-11-23 2026-11-24" data-d-return="2026-11-27" data-d-event="2026-11-25" and calls arabelaDF.has(row, date, kind). A page that keeps its rows as data (All Bookings) calls arabelaDF.hit(list, date) instead. An empty or malformed date means "any date" (everything shows), so a half-typed date can never hide the whole list. {% endcomment %}
