{% comment %} The GCash reference number of a payment, shown big and clear at the top of a payment proof window, with a Copy button: it is the number the owner looks for in her GCash app (and the one searchable in the admin lists). Used by every window that shows a payment proof (Pending Approval, Payment Verification, Security Deposits, the Dashboard's Quick Verify), so the number looks the same everywhere. Parameter: var -- the page's own Alpine variable that holds the window's data (viewingPayment / receiptPreview). It carries refInfo (Reservation.reference_info_json): { reference, digits, typed, match, referenceDiffers, amountDiffers, receiptReference, typedAmount, receiptAmount } or null when the booking has no reference (a walk-in), in which case nothing is shown. When the customer typed the number the picture does not show, the number shown is the one typed, with a plain line saying what the receipt reads. Own gr- names (the admin CSS build is sparse); the dark twins follow the page's `.dark` class. {% endcomment %}
