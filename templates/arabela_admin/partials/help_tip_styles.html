{% comment %} The small round "?" that explains something on demand, so the explanation is not printed on the page all the time. Same look as New Booking's "?" (its own .nb-tip is left as it is). Included ONCE per admin page from partials/notifications.html (the header partial every admin page has), so no page has to include it again. Use it next to a title or a label. NEVER inside a button, and never inside a label element that wraps a control: a click on the "?" would be taken as a click on that button or control. The markup (shown here with entities so that it is not read as markup): <details class="ht-tip"><summary aria-label="About blocked dates" title="About blocked dates">?</summary><div class="ht-tip-pop">The explanation.</div></details> Plain script, no framework: it also works in the windows and on the pages that are not built on Alpine. A click outside or Escape closes it (Escape closes ONLY the "?" while one is open, not the window behind it), and a bubble that would run off the edge of the screen -- or past the edge of the pop-up window panel it is in, which would cut it off -- is made narrower / slid back inside (or opened above the "?" when there is no room below it). {% endcomment %}
