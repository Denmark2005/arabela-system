{% comment %} Admin dialog: styled, animated replacement for window.confirm / alert / prompt. Self-contained (markup + CSS + JS) with its own .adm-dlg-* namespace -- the admin stylesheet is a precompiled Tailwind build containing only the template pack's own classes, so this deliberately depends on none of them. Follows the panel's dark mode via the `.dark` class Alpine puts on . API (all return a Promise): adminConfirm({title, message, confirmText, cancelText, danger}) -> bool adminAlert({title, message, confirmText}) -> true adminPrompt({title, message, placeholder, confirmText}) -> string|null NOTE: must be {% comment %}, not {# #} -- Django's hash comment is single-line only, so a multi-line one renders as visible text on every page that includes this partial (which is exactly what it was doing). {% endcomment %}
