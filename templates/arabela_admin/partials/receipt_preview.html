{% comment %} The Receipt preview window: a "Receipt" button anywhere in the admin calls arabelaReceipt.open(reservationId) (or arabelaReceipt.open(reservationId, {payment: id}) to land on one receipt). It shows the receipt exactly as it prints (the same paper as the Payments page: templates/partials/receipt_paper.html, loaded in a frame from the print page with ?look=1&embed=1, which does NOT count as a print), a status pill, and Close / Print Receipt. Print Receipt opens the printable page in the frame WITHOUT look=1, so it counts as the original or a reprint exactly like the Payments page's Print, then opens the browser's print window. A Paper choice (80 mm roll, 58 mm roll, normal page) is remembered on this computer. Included ONCE per admin page from partials/notifications.html. Self-contained: its own CSS (class prefix rcm-), light and dark. Everything that comes from the server is put on the page as plain text (never as HTML). {% endcomment %}
