{% comment %} Every admin date box gets a visible calendar icon on its right; a click on that icon opens the calendar. A click on the date itself (month, day, year) does NOT open it, so a date can still be typed: opening the calendar on every click was tried before and dropped, because the open calendar takes the keyboard and the date could no longer be typed. Why this is needed: the admin theme's stylesheet hides the browser's own calendar button on every date box, and only a few boxes had a script of their own to open it, so most date boxes looked typing-only. One rule and one click handler for all of them replaces the per-box scripts. Included ONCE per admin page from partials/notifications.html. The icon is a background picture (not the browser's button), so it looks the same in every browser, and !important is used so that a box's own `background: transparent` or Tailwind `bg-none` / `px-4` classes cannot remove it or sit the text on top of it. {% endcomment %}
