{% comment %} The "GCash Payment Proof" window: the customer's proof (or the shop's own receipts), a link to the full image, the reference, the amount (with its breakdown) and a warning when the same GCash number is on another booking. Opened in place, on the page that needs it, instead of sending staff to Payment Verification and back. Parameters: var the page's own Alpine variable that holds what to show (viewingPayment). The row's View button fills it with { name, bookedAs, reservation, reference, amount, date, status, proofUrl, receipts, breakdown, gcashRef, gcashDup }. flag the page's Alpine on/off flag for this window (openReceiptModal). with_actions pass 1 to add Approve / Reject at the bottom (Pending Approval): the staff member checks the proof and decides here. The variable then also carries { approveUrl, rejectUrl, walkin, receiptCount }. The buttons run the page's own reviewReservation(btn) -- the same confirm / reason window, the same server action as the buttons on the booking's line. Closes with the X in the corner (or a click on the dim area). Same look as the receipt windows on Dashboard / Payment Verification / Security Deposits. Needs partials/payment_breakdown.html's styles, which this file brings in. {% endcomment %}
