{% comment %} The gown photo window: click a gown's NAME on Active Reservations, Reservation Records or Pending Approval and this opens with that gown's picture. The look is the Gown Catalog's photo window (same white card, same close button, the photo whole and never cropped), but it is view-only: no "Replace Photo", no "View Full Image" (those stay in the Gown Catalog), and the title is the gown's name. Included ONCE per page, next to partials/dialog.html. Self-contained (markup + CSS + script) in its own .gpw namespace, because the admin stylesheet is a precompiled Tailwind build that holds only the template pack's own classes. Follows dark mode through the `.dark` class Alpine puts on . How a name opens it: put these on the name's element (the pages do; Reservation Records binds them with Alpine): data-gpw-name="Wedding Gown 17" the title (its presence is what marks the element) data-gpw-sub="White tag · WH-017 · Large" the line under the title (optional) data-gpw-photo="https://..." the picture ("" = no photo: the window says so) role="button" tabindex="0" so the keyboard can reach it (Enter or Space opens it) ONE click listener for the whole page (capture phase), so a row that is swapped in later by the live updates (live-regions.js) works with nothing to re-bind. While the window is open the page is "busy" for those live updates (it is a role="dialog" that shows). Safety: the picture address is used only when it is a normal web address (http / https) or a path on this site; the name and the line under it are put in as plain text, never as HTML; a picture that cannot be loaded says so. A click on a name is handled here and goes no further, so it never also opens or closes the booking row it sits in; and while the window is open every click and the Escape key stay inside it, so the window it was opened from (Reservation Records' View window) stays open.
